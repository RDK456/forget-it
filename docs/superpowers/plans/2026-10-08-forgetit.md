# Forget-it Implementation Plan

> **For agentic workers:** Execute task-by-task (superpowers:executing-plans). TDD for every `domain` task: failing test, run, implement, run, commit. The spec carries all rules and numbers; this plan carries order, files and interfaces.

**Goal:** A working beta of Forget-it: an offline Android app tracking subscriptions, EMIs/loans and household stock, with photos and reminders.

**Spec:** `docs/superpowers/specs/2026-10-08-subtrack-design.md` (read it first; section numbers below refer to it).

## Global Constraints

- Package/applicationId `app.forgetit`; minSdk 26, target/compile 35; Kotlin 2.0.21, AGP 8.7.3, Gradle 8.11.1, JDK 17, Compose BOM 2024.12.01, Room 2.6.1 (KSP 2.0.21-1.0.28), Coil 2.7.0, Glance 1.1.1, WorkManager 2.10.0, Biometric 1.1.0.
- No `INTERNET` permission, no exact-alarm permission, `allowBackup=false`, no DI framework, no chart/calendar library.
- `domain` has no Android imports; time injected (`Clock` or `today`/`now` params); money is `Long` minor units with `BigDecimal` math.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus (each pinned by a test in the task named)

1. Month-end/leap-day anchors (A2). 2. JPY/KWD parse/format/convert (A3). 3. Comma/blank/garbage amount input (A3). 4. Reminder for deleted/inactive/already-notified record shows nothing (A8). 5. CSV commas/quotes/newlines/BOM/CRLF/formula cells (A11, B4, C4). 6. Loan: 0% rate, EMI override, final-installment payoff, each adjustment, EMI-too-low (B1). 7. Stock: expired batches skipped on use, usage-rate threshold, over-consumption (C1).

## Plan A: Foundation + Subscriptions

- **A1 Skeleton:** install JDK 17, `git init`, Gradle wrapper, Compose app showing "Forget-it", builds and launches on the emulator.
- **A2 Renewal:** `domain/Subscription.kt` (`Cycle`, `Subscription`, `CATEGORIES`, `isTrialActive`, `settleTrial`), `domain/Renewal.kt` (`occurrence`, `next`, `between`). Tests: weekly/monthly/quarterly/yearly/custom, month-end, leap day, future start, trial lifecycle.
- **A3 Money/Cost/Totals/Validator:** `Money` (`fractionDigits`, `isValidCurrency`, `parseMinor`, `format`), `Cost` (`monthlyExact`, `monthlyMinor`, `yearlyMinor`, `round`), `Totals` (`monthlyInDefault`, `computeTotals`), `Validator` (`ValidationError`, `validate`).
- **A4 Data:** Room `AppDatabase` v1 (`subscription`, `photo`, `reminder_log`), entity mappers, `SubscriptionRepository` (validates, `settleTrials`), `SettingsStore` (default currency, rates with edit date, reminder minute, theme, biometric flag). `AppContainer` wiring. Room instrumented test.
- **A5 Shell:** `ForgetItTheme`, 5-tab navigation (Overview, Subscriptions, Loans, Stock, More), Overview (outgo card, coming-up list), Subscriptions list with total card, search, category filter, delete-with-undo.
- **A6 Edit:** subscription Add/Edit screen with field errors, trial toggle, currency, date picker, `domain/Presets.kt` (~30 services), avatar.
- **A7 Photos:** `PhotoStore` (downscale 1280 px JPEG q80, EXIF rotate, orphan sweep), `PhotoRepository`, camera (TakePicture + FileProvider) and PickVisualMedia, thumbnail strip, full-screen pager viewer, Coil.
- **A8 Reminders:** `domain/ReminderPlanner.kt` (`ReminderSpec`, `ReminderKind`, subscription specs, `shouldNotify`), `reminders/` (channels, `ReminderScheduler`, `ReminderReceiver`, `BootReceiver`, `DailyCheckWorker`, `NotificationHealth`), single sync collector in `AppContainer`, `POST_NOTIFICATIONS` request.
- **A9 Calendar + Insights:** `domain/ChargeCalendar.kt`, `domain/Insights.kt`, Canvas donut, month grid.
- **A10 Settings + Lock:** settings screen (currency, rates, reminder time, theme, notification health), `BiometricGate` + `FLAG_SECURE`.
- **A11 CSV:** `domain/CsvCodec.kt` (RFC 4180, BOM, CRLF, formula-injection guard), subscriptions export/import via SAF.
- **A12 Widget:** Glance widget, refreshed by the sync collector and daily worker. Emulator verification pass.

## Plan B: Loans/EMI

- **B1 Engine:** `domain/Loan.kt` (`Loan`, `LoanPayment`, `LoanAdjustment`), `domain/Amortization.kt` (`schedule(loan, adjustments, payments, today)` returning rows with status, `summary`). Spec section 7 rules.
- **B2 Data:** migration 1→2 (`loan`, `loan_payment`, `loan_adjustment`), DAO, `LoanRepository`, migration test.
- **B3 Screens:** Loans list, detail (schedule, mark paid, prepayment, balance reset), Add/Edit with photos.
- **B4 Integration:** EMI reminders, calendar, overview outgo, insights slice, widget, `loans.csv`.

## Plan C: Household stock

- **C1 Engine:** `domain/Stock.kt` (`StockItem`, `StockBatch`, `StockLog`), `domain/StockEngine.kt` (usage rate, estimate, run-out, low, FEFO use skipping expired, restock, discard). Spec section 8 rules.
- **C2 Data:** migration 2→3 (`stock_item`, `stock_batch`, `stock_log`), DAO, `StockRepository`, migration test.
- **C3 Screens:** Stock list (expired/low/ok), item detail (batches, Use/Restock/Discard, history), Add/Edit with photos.
- **C4 Integration:** low-stock and expiry reminders, calendar, overview, `stock.csv`.

## Definition of beta

`./gradlew testDebugUnitTest` green, `./gradlew assembleDebug` succeeds, and on the emulator: add a subscription, a loan and a stock item with a photo each; each shows on Overview and Calendar; a test reminder notification appears; export/import CSV works.
